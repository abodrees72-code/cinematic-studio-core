# Asset Manifests

This directory tracks external production assets without storing restricted or heavy asset payloads by default.

Each approved asset should eventually have a versioned manifest that records identity, provenance, license state, redistribution state, local storage reference, hash when available, approved production scope, and QA notes.

No third-party asset payload is considered safe to commit merely because it is free, purchased, or downloadable. Redistribution rights must be explicitly proven first.
